## Changes

- Added transport-independent Go card and engine domain code under `apps/server/internal/game/`.
- Added validated construction for 0–31 variants and MSB-first attribute mapping, Hamming distance, and the baseline zero-or-one-difference matching rule.
- Added separate per-board card instance identities, seeded deterministic private generation, configurable board size/score award, and copy-safe snapshots.
- Added correct/incorrect pick transitions: correct picks advance score, combo, reference and versions while replacing the selected slot; incorrect picks only reset combo. Technical unknown-card errors leave state and PRNG unchanged. Cooldown and stale-action checks remain with future caller layers.
- Added initial-board and post-correct replacement fallbacks to preserve a valid choice. The conditional fallback and its limited sampling effect are documented as a proposed technical choice in the approved Work Item specification.
- Added exhaustive ordered-pair, mapping, determinism, solvability, scoring, combo, identity, replacement, snapshot-copy, and atomic-error tests.

## Documentation, limitations, and follow-ups

- The engine is intentionally not concurrency-safe; W009/W011 must serialize actions in the owning Room context.
- The engine does not own mistake cooldown, timer boundaries, session authorization, stale-state checks, or WebSocket publication. Caller layers enforce them before invoking the gameplay transition.
- Per-engine IDs are unique within that player's board scope; protocol identity also includes Match/player context.
- The engine uses a deterministic seed supplied by its caller. W011 must obtain and retain production seeds securely and must not expose future generation state.
