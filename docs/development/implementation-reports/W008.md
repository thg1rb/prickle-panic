## Changes

- Added the transport-independent session domain in `apps/server/internal/session/`: opaque guest IDs, 32-byte CSPRNG credentials, SHA-256 verifier indexing, credential redaction during formatting, explicit invalidation, activity-qualified lookup, idle and absolute expiry, indexed proactive deadline scheduling, and atomic rolling session-creation quotas.
- Added `apps/server/internal/clock/` for paired UTC and process-monotonic ticks and injectable timers.
- Added `apps/server/internal/clientip/` for direct-peer source resolution and right-to-left `X-Forwarded-For` handling only behind configured trusted CIDRs. It ignores forwarded metadata from untrusted peers and does not consume `Forwarded` or `X-Real-IP`.
- Implemented NFC normalization, UAX #29 extended-grapheme counting, Thai/English/digit/space allowlisting, and rejection of controls, format characters, standalone/repeated Thai marks, emoji, unsupported scripts and punctuation, and overlong input.
- Added the bounded at-least-once expiry event queue, stable event IDs, retry backoff, pending-event retention, typed backpressure, and authorization revocation before delivery. Manual revocation does not masquerade as timeout expiry.
- Added deterministic and concurrent tests for session lifecycle, idle/absolute expiry, quotas, credential hashing/formatting/uniqueness/collision retry/entropy failure, Unicode cases, proxy trust/config validation, bounded-key behavior, retry stability, and outbox backpressure.
- No HTTP endpoints, cookies, WebSocket handling, Room logic, Match forfeit, frontend behavior, or unrelated Work Items were implemented.
